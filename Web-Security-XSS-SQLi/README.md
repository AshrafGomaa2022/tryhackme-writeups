# Web Application Security Testing

## Objective
Identify basic web vulnerabilities like XSS and SQL Injection.

## Techniques Used
- Input manipulation
- Basic SQL injection attempts
- XSS payload testing

## Results
- Reflected XSS confirmed in lab environment
- SQL Injection bypass observed in login form

## What I Learned
- How insecure input handling leads to vulnerabilities
- Importance of input validation and sanitization
