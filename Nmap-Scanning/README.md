# Network Scanning using Nmap

## Objective
Learn how to discover open ports, services, and potential attack surfaces.

## Tools Used
- Nmap

## Commands Used
- nmap -sS <target>
- nmap -A <target>
- nmap -p- <target>

## Results
- Port 22: SSH
- Port 80: HTTP
- Port 443: HTTPS

## What I Learned
- How attackers map networks
- Importance of reducing exposed services
- Basics of reconnaissance in cybersecurity
